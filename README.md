# Dafe

AI voice agent that prevents drug-related problems (DRPs) in older adults with chronic kidney disease and polypharmacy. Team PharmPharm, UU Digital Healthcare Hackathon 2026. Prototype with fake data only.

- `web/`: the app (Next.js). Run and demo instructions are in [web/README.md](web/README.md).
- `data/team-inputs/`: the clinical team's source files (rule tables, virtual patient, speaker script).
- `CLAUDE.md`: project brief, constraints and team context.

Dafe never diagnoses or changes doses. It checks, records and forwards. The doctor decides.
